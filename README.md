# 📚 Projeto LGPD – Trabalho Acadêmico  

Trabalho acadêmico sobre a **Lei Geral de Proteção de Dados (LGPD)**, desenvolvido em **HTML, CSS e JavaScript**.  
O objetivo é apresentar os principais pontos da lei de forma **visual, interativa e didática**.  

🔗 **Acesse o projeto online:**  
👉 [GitHub Pages](https://zatticode.github.io/trabalho-faculdade-lgpd/)  

---

## 🚀 Tecnologias  
- HTML5  
- CSS3  
- JavaScript (ES6+)
