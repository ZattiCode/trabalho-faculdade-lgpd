📚 Projeto LGPD – Trabalho Acadêmico

Este repositório contém um projeto acadêmico sobre a Lei Geral de Proteção de Dados (LGPD), desenvolvido com o objetivo de apresentar os principais pontos da lei em uma interface web simples, didática e interativa.

🔗 Acesse o projeto online: GitHub Pages – Projeto LGPD

📝 Descrição

O projeto tem como finalidade:

Explicar de forma visual e objetiva os princípios da LGPD.

Destacar a importância da proteção de dados pessoais no contexto digital.

Servir como material de estudo para fins acadêmicos e educacionais.

O conteúdo foi estruturado em HTML, CSS e JavaScript, com páginas interativas e imagens ilustrativas para facilitar a compreensão.

📂 Estrutura do Projeto

index.html → Página principal do projeto.

style.css → Arquivo de estilos e layout visual.

script.js → Funções JavaScript para interatividade.

tabela.html → Conteúdo complementar em formato de tabela.

contato.html → Página de contato.

fonte.html → Referências utilizadas no trabalho.

Imagens → Arquivos (LGPD1.png, LGPD2.png, LGPD3.png, LGPD4.png) usados para ilustrar tópicos da lei.

🛠️ Tecnologias Utilizadas

HTML5 → Estrutura e conteúdo.

CSS3 → Estilização e responsividade.

JavaScript (ES6+) → Interatividade e dinamismo.

🎯 Objetivos Educacionais

Facilitar a compreensão da LGPD para estudantes e profissionais.

Demonstrar na prática conceitos como:

Direitos dos titulares de dados;

Princípios de tratamento de dados;

Responsabilidade e segurança;

Consentimento e eliminação de dados.

Servir como referência inicial para futuros projetos na área de privacidade digital.
